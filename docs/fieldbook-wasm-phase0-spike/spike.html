Fieldbook browser Phase 0 spike

Two questions this page answers, without any build tools, with two distinct browser DuckDB stacks loaded from CDN:

  1. Vanilla `@duckdb/duckdb-wasm` works in-browser — a hard-coded CREATE TABLE demo AS SELECT range::INT AS x, x*x AS y FROM range(20) renders below.
  2. Can it load our fieldbook.wasm component?  No — @duckdb/duckdb-wasm is an Emscripten build of DuckDB C++ that loads .duckdb_extension shared objects from a fixed curated URL list. Our fieldbook is a duckdb:extension WIT component for the ducklink-team's separate ~/git/duckdb-wasm/ core. The two stacks are incompatible — see the memo.
